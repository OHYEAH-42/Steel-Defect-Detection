## 3. 两个方向的取舍摘要

| 维度 | 钢材六分类 | 垃圾分类与投放辅助 |
|---|---|---|
| 入门模型 | CNN、ResNet18 迁移学习 | 同样可以使用 CNN、ResNet18 |
| 基础公开数据 | NEU-CLS：1,800 张，6 类，各 300 张 | TrashNet：2,527 张，6 类，各 137–594 张 |
| 主要视觉线索 | 纹理、线条、斑块和灰度 | 形状、颜色、材质和物品外观 |
| 主要实验风险 | 相似纹理混淆、近重复泄漏、过拟合 | 类别不均衡、背景依赖、实拍分布变化 |
| 应用边界 | 缺陷类别不等于合格判定 | 材质类别不等于当地投放类别 |
| 额外场景工作 | 入门版可主要使用公开数据 | 校园版建议实拍验证和投放规则整理 |
| 展示特点 | 需解释缺陷类别，偏专业 | 更生活化、互动直观 |
| 当前建议 | 优先作为课程工作选题 | 有明确场景兴趣及采集时间时再考虑 |

这两个入门项目的模型代码难度接近。钢材当前较易控制的是项目范围和交付过程，不应据此认为缺陷纹理识别本身没有难度。

## 4. 建议锁定的任务范围

### 4.1 输入与输出

- 输入：一张预期属于 NEU-CLS 六类已知缺陷之一的钢材表面图像。
- 输出：预测类别、六类模型输出概率、输入图像预览及适用范围说明。
- 分析页面：真实测试指标、混淆矩阵、训练曲线、模型迭代对比和错误案例。

模型概率不是已校准的真实正确率。未知图片即使获得高分，也不能据此判定识别可靠。

- 正常/异常检测、质量合格判定和缺陷严重程度判断。
- 未知缺陷可靠识别、缺陷框定位或像素分割。
- YOLO、多模型大规模搜索、工业相机、生产线实时部署。
- 登录、数据库、完整小程序和复杂云平台架构。

增加上述能力需要重新界定任务、准备对应标签并调整验收条件，不能仅通过修改页面描述获得。

## 5. 数据获取、样本量与处理

### 5.1 首选数据：NEU-CLS

官方说明为 1,800 张灰度图，原始尺寸 200×200，六类各 300 张：Crazing、Inclusion、Patches、Pitted Surface、Rolled-in Scale、Scratches。

优先使用东北大学官方页面的分类数据入口，区分 NEU-CLS 与 NEU-DET。下载后核验实际文件，记录来源、下载日期、类别映射、归档文件及使用条件。

### 5.2 数据处理建议

1. 统计实际数量、尺寸、通道、损坏图像、完全重复及疑似近重复。
2. 对疑似近重复人工复核；若有同源批次或连续拍摄信息，优先按组划分。
3. 固定训练/验证/测试清单，建议分层 70%/15%/15%。完整均衡情况下分别为 1,260/270/270 张，各类为 210/45/45 张。
4. 训练前将灰度图复制为三通道，输入尺寸可从 224×224 开始，归一化与所用预训练权重匹配。
5. 训练可使用经过样例检查的适度翻转、旋转或亮度变化；验证、测试和网页推理使用确定性处理。
6. 避免裁掉细小缺陷、过度模糊纹理；放大图片不会增加原始细节。
7. 清洗后若数量变化，按实际记录，不删除困难样本以追求高指标。

### 5.3 样本量的解释

1,800 张可支持课程中的小样本迁移学习实验，不能单独证明工业适用性。每类测试仅约 45 张，多错一张会让该类召回率变化约 2.2 个百分点，因此小幅提升需谨慎解释。

数据增强、连拍、裁剪及同一图片的不同下载镜像都不能当作新增独立样本。

### 5.4 其他数据的用途

| 数据 | 特点 | 建议用途与限制 |
|---|---|---|
| NEU-DET | 六类缺陷的定位标注 | 若后续改做检测可考虑；与 NEU-CLS 可能同源，不作为独立外部数据直接混用 |
| GC10-DET | 十类金属表面缺陷，框级标注 | 适合检测扩展；版本数量需下载核查，类别不能直接等同 NEU 六类 |
| Severstal | 公开训练约 12,568 张，存在正常与多缺陷图，提供分割标注 | 可另做正常/异常、多标签或分割任务；不直接套用互斥六分类 |
| MVTec AD | 超过 5,000 张、15 种物体/纹理类别 | 属于工业异常检测扩展，不是钢材专用补充集 |

当前不建议仅为扩大总量而合并不同数据集。若后续使用，先检查类别语义、成像差异、重复及来源，再确定独立评价或适配方案。

## 6. 模型路线与迭代策略

### 6.1 必做 C0：冻结主干

- 使用 ImageNet 预训练 ResNet18，分类层改为六输出。
- 冻结主干，只训练分类层；需同时明确 BatchNorm 运行统计量是否固定，不能仅凭 `requires_grad=False` 就声称全部特征行为固定。
- 建议起点：CrossEntropyLoss、Adam、分类层学习率 1e-3、batch size 16 或 32，按实际设备调整。
- 记录每轮训练/验证损失、Accuracy、验证 Macro-F1、耗时及最佳轮次。
- 依据验证集选择权重，保存配置、映射、预处理和划分版本。

### 6.2 必做 C1：部分微调

- 从 C0 最优权重出发，解冻 `layer4` 和分类层，以较小学习率继续训练，例如从 1e-4 起试。
- 保持相同数据划分与评价流程，比较指标和成本。
- C1 不要求必然提升；下降也应保留并分析。
- C1 同时增加训练预算，不能把全部变化归因于解冻。如果要严格回答解冻的因果效果，追加训练预算相近的继续冻结训练对照。

### 6.3 可选扩展，每次只选一个明确问题

| 扩展 | 对应研究问题 |
|---|---|
| 简单 CNN 从零训练 | 小数据情况下，基础 CNN 与迁移学习有何差异？ |
| 纹理特征或 HOG＋SVM | 手工特征和学习特征的差异是什么？ |
| 固定强度的亮度、噪声等扰动 | 模型对成像变化有多敏感？ |
| 随机初始化 ResNet18 | 在合理控制训练条件后，预训练带来什么变化？ |

先完成 C0 与页面，再完成 C1、分析和报告。只有核心交付完成后才追加模型；不因模型数量少而盲目扩展。

## 7. 评价、解释与可信结论

- 必备指标：Accuracy、Macro-Precision、Macro-Recall、Macro-F1、各类 Precision/Recall/F1、混淆矩阵。
- 保留训练与验证曲线、真实误分类图、输入处理说明及训练/推理成本。
- 验证集负责选择模型与参数；实验方案锁定后再进行最终测试，不根据测试结果返回调参。
- C0/C1 如需最终测试对照，应在测试前确定比较方案，不能利用对照结果继续挑模型。
- 若资源允许，对主要方案用少量不同随机种子重复训练，报告均值与波动，不只报最好的一次。
- 热力图可作为可选分析辅助，不能单独证明模型判断正确、因果解释成立或可以准确定位缺陷。
- 成绩差、微调退化或外部图片失败都应如实说明；不承诺未经实测的准确率与毫秒延迟。

建议特色：选择一个可回答的问题，例如“冻结与部分微调怎样影响各类别表现和训练成本”，或“亮度变化对相似纹理缺陷分类有什么影响”。特色来自数据和分析证据，而不是增加功能名词。
