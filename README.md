# 基于迁移学习的钢材表面缺陷分类与可视化分析系统

机器学习课程设计项目。使用公开数据集 NEU-CLS（六类钢材表面缺陷，原始说明为 1,800 张灰度图），以 ImageNet 预训练 ResNet18 进行迁移学习分类，并提供本地运行的 Streamlit 单图分类与实验分析页面。

适用范围：输入图像应属于六类已知缺陷之一。本项目不判断质量是否合格，不识别未知缺陷，不做缺陷定位，不面向工业部署。
